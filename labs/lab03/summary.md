# Lab03 RISC-V 链表map实验 精简总结
## 一、四类寄存器速记
| 寄存器 | 名称 | 核心用途 | 使用约束 |
|--------|------|----------|----------|
| x0 | 零寄存器 | 永久存0，拷贝/判空 | 只读，不可修改 |
| a0~a7 | 参数寄存器 | 函数入参、返回值（返回值固定a0） | 调用子函数后数据丢失，不能长期存数据 |
| s0~s11 | 保存寄存器 | 长期留存核心数据（节点地址/函数指针） | 函数开头栈备份，结尾栈恢复 |
| t0~t6 | 临时寄存器 | 小段临时计算中转 | 无需栈备份，用完即丢 |

口诀：`x0恒零；a传参存返回；s栈备份长期存；t临时用完丢`

## 二、代码模板
### 1. 定次循环模板（创建链表）
```asm
# 初始化
li s0, 0
li s1, 0
loop:
    # 循环业务
    li a0,8
    jal ra,malloc
    sw s1,0(a0)
    sw s0,4(a0)
    add s0,a0,x0
    addi s1,s1,1
    # 终止判断
    addi t0,x0,10
    bne s1,t0,loop
```

### 2. 递归map核心代码（截图完整代码块）
```asm
map:
# Prologue: 栈备份 ra s0 s1
addi sp, sp, -12
sw ra, 0(sp)
sw s0, 4(sp)
sw s1, 8(sp)

# 1. 递归基线：空链表直接结束
beq a0, x0, done

# 2. 备份核心数据到s寄存器
add s0, a0, x0
add s1, a1, x0

# 3. 当前节点处理逻辑
lw a0, 0(s0)
jalr ra, s1, 0
sw a0, 0(s0)

# 4. 准备递归参数，处理下一个节点
lw a0, 4(s0)
add a1, s1, x0
jal ra, map

done:
# Epilogue: 恢复寄存器、回收栈
lw ra, 0(sp)
lw s0, 4(sp)
lw s1, 8(sp)
addi sp, sp, 12
jr ra
```
递归要点：
1. 必须基线出口 `beq a0,x0,done`，防止无限递归
2. 跨递归数据存入`s寄存器`并栈备份
3. 递归前补齐map双入参：`a0=下节点、a1=转换函数指针`

## 三、汇编数据结构题通用解题步骤
1. **拆分函数**：模块化拆分创建/遍历/打印/转换函数，约定每个函数a0/a1入参规范
2. **规划寄存器**：临时计算用`t`；传参交互用`a`；长期核心数据强制用`s`并补栈操作
3. **套模板编码**：所有自定义函数统一「Prologue栈备份 → 边界判断 → 业务逻辑 → 迭代/递归推进 → Epilogue栈恢复」
4. **分段调试**：分步测试链表创建、转换函数、递归遍历，打印输出验证结果；单步跟踪sp、a0、s0排查寄存器覆盖、栈失衡问题

## 四、实验感悟
1. 汇编无自动变量保护，寄存器分工混淆是绝大多数bug根源，本次调试整晚均因a/s寄存器混用导致数据丢失；
2. 递归链表遍历核心是「基线出口+节点处理+递归推进」，栈帧备份`s/ra`是递归程序稳定运行的前提；
3. 带函数指针、结构体内存读写的综合汇编题，禁止一次性写完再调试，按「寄存器规划→模板填充→分段验证」流程能大幅降低调试成本；
4. 严格遵守RISC-V调用约定（参数a0~a7、返回值a0），才能写出通用可复用的map遍历函数。
